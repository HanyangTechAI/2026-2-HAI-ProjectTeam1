# 2-2. Ablation Test — 2K × H100

**수정 전 v1.0.3 결과:** 아래 `no_temporal`은 Temporal Resolution과 Mandatory State를 함께 제거한 조건이다. v1.0.4의 Temporal 단독 제거 조건은 이후 80회 재실행을 완료했고 성공률은 90.0%였다. [별도 보고서](no_temporal_v104_2k_h100_20261111.md)에 기록했다.

2026-11-11 실행. Full Proposed와 구성 요소 제거 4개 조건을 같은 40개 합성 과제에서 각각 2회 반복했다. **계획한 400/400회가 완료됐다.** 입력은 기존 Main 실험의 Gemini 3.1 Flash-Lite 측정 2K·H100 셀을 그대로 사용했다. 실행 코드는 `2f5e6bc`(freeze 1.0.3)이며, 모델은 `gemini-3.1-flash-lite`, 출력 상한은 2048 token, 입력 안전 여유는 32 token이다.

| 조건 | 성공 | Full 대비 성공률 차이 (Full − 제거, 95% CI) | 현재 State의 stale 사용 | 평균 입력 token | 평균 LLM 추정 비용 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Full Proposed | 78/80 (97.5%) | 기준 | 0/60 | 1,470 | $0.001563 |
| Constraint Preservation 제거 | 80/80 (100.0%) | −2.5pp [−7.5, 0] | 0/60 | 1,474 | $0.001567 |
| Temporal Resolution 제거 | 72/80 (90.0%) | +7.5pp [−2.5, 20] | 8/60 (13.3%) | 1,633 | $0.002070 |
| State Mandatory 제거 | 78/80 (97.5%) | 0pp [0, 0] | 0/60 | 1,470 | $0.001563 |
| Token-aware Packing 제거 | 78/80 (97.5%) | 0pp [0, 0] | 0/60 | 1,470 | $0.001554 |

짝지은 차이는 같은 sample·repeat 80쌍을 사용하고 40개 기본 과제를 군집으로 묶어 bootstrap 2,000회(seed 42)로 구했다. `no_temporal`의 성공률 하락과 stale 사용은 시간 해석의 기여를 시사하지만 차이의 신뢰구간이 0을 포함한다. 이 preset은 구현 제약에 따라 **Temporal Resolution과 State Mandatory를 함께 끈다**. 따라서 두 기능의 효과를 완전히 분리한 결과가 아니다. Constraint Preservation 제거의 100%도 Full보다 우월하다는 증거로 보기 어렵다. 성공 차이 2회는 동일한 승인 대기 기본 과제(`seed43_approval_014_pending`)의 두 반복에서 발생했고 신뢰구간은 0에 닿는다. State Mandatory와 Token-aware Packing 제거는 이 입력 분포에서 성공 판정이 Full과 같았다.

모든 조건의 승인 제약 위반은 0/40회였다. 전체 400회에서 실행 상태는 모두 `completed`, prompt audit은 모두 `verified`, 실제 입력 예산 초과는 0건(최대 1,823 token), 비용 회계는 모두 `complete`였다. 834번의 LLM API 호출에 대해 기록된 **LLM 추정 비용 합계는 $0.665266**이다. 이는 CountTokens 호출이나 기타 인프라 비용을 포함한 청구 총액이 아니다. 두 반복은 같은 기본 과제를 공유하므로 독립 과제 80개로 해석하지 않는다. 또한 이 결과는 2K·H100 합성 과제에 한정된다.

재현용 원본 실행물은 `experiments/results/ablation/2k_h100_20261111/`에 로컬 저장됐다. 저장소에 포함되는 집계와 검증 기록은 [summary.json](results/ablation_2k_h100_20261111/summary.json), [deltas.json](results/ablation_2k_h100_20261111/deltas.json), [validation.json](results/ablation_2k_h100_20261111/validation.json)이다. `validation.json`에는 입력 셀과 원본 run 파일의 SHA-256이 기록돼 있다.

후속 2K/4K 비교와 freeze 1.0.4 Full-only 재검증은 [Ablation 비교·재검증 보고서](ablation_2k_h100_analysis_20261111.md)에 기록했다. Full-only 재검증은 수정된 v1.0.4 `no_temporal` 변형을 실행한 결과가 아니다.
